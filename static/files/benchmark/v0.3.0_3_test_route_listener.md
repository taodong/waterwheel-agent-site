# Test Route Listener
## Summary
This test is to verify emails are delivered to a subscription route through an active `Route Listener`. 

## Steps
1. **Get Test User:** Verify that `context.testuser` exists in the context manager. If it is missing, fail the test immediately with the reason: "Test User is missing"
2. **Login:** Open a browser tab and navigate to `LOGIN_URL` and perform login using the retrieved credentials.
3. **Open Channel Config Page:** Click `Manage` button at the row of `a_${context.testuser.username}` to open channel page `Channel a_{context.testuser.username}`.
4. **Enable Route Listener:** On the channel page, click `Add Route Listener` button to open `Add Channel Listener` dialog. Select `news` from `Route ID` dropdown then click `Save` button to close the dialog.
5. **Verify `news` Route Listener:** Verify that a banner with text `Route listener is on for news` displays on channel page.
6. **Send Test Email:** Use Email MCP to send the following email payload
    ```json
    {
        "from": "boucne@newsletter.newsc.com",
        "to": ["a_${context.testuser.username}_news@duotail.com"],
        "subject": "5 Things Worth to Know Today",
        "content": "Here are 5 things you need to know today."
    }
    ```
7. **Verify Email Received:** Use Email MCP to verify an email with title `5 Things Worth to Know Today` and from address `1_a_${context.testuser.username}_news@duotail.com` is received.
8. **Verify Route Listener is Closed:** Return to channel page for `Channel a_{context.testuser.username}` and refresh the page. Verify no banner contains text `Route listener is on` exist on the page.
9. **Verify Domain Permissions:** Click the `Update` button on the `news` row to open the `Edit Route` dialog. Click the `Permissions` tab inside the dialog. Verify both `newsc.com` and `newsletter.newsc.com` appear as green pills. If either is missing, fail the test with the reason: "Domain permission missing: `${domain}` not found in Permissions tab of route `news`". Once both pills are confirmed, complete the test as SUCCESS.
