# Support

## Get Support

Need a hand? Pick the channel that matches what you're after — it helps us route
your request to the right place.

| I want to… | Go to |
|---|---|
| Report a bug or unexpected behavior | [GitHub Issues](https://github.com/taodong/waterwheel-agent-site/issues) |
| Ask a usage or how-to question | [Discord community](https://discord.gg/6kDkXr5Teh) |
| Reach us about anything else | [contact@duotail.com](mailto:contact@duotail.com) |

:::tip[Before opening an issue]
Check the [Release Notes](./release-notes) to confirm you're on the latest
version — many questions are already resolved in a newer release.
:::
