# Release Notes

The Waterwheel agent is distributed as a pre-built Docker image, free to use.

**Docker image:** [taojdcn/duotail-waterwheel](https://hub.docker.com/r/taojdcn/duotail-waterwheel)

:::tip[Use the latest release]
We recommend always running the latest version, **`1.3.0`**.

```shell
docker pull taojdcn/duotail-waterwheel:1.3.0
```
:::

## 1.3.0 — latest

The current release. It makes every part of the agent scriptable and introduces the
[Waterwheel skills](./agent-loops) for pairing the agent with a code agent in a
nested test-and-fix loop.

- **Agent loops & skills** — a set of Claude Code skills that install, configure, and
  drive the agent automatically, enabling an autonomous, test-driven web development
  workflow. See the new [Agent Loops](./agent-loops) guide.
- **Non-interactive setup** — configure the agent from scripts and CI without the
  interactive prompts of `config-agent`:
  - [`config-ai-provider`](./usage#config-ai-provider-command) — apply an AI provider
    and model directly.
  - [`set-domain-permission`](./usage#set-domain-permission-command) — generate the
    browser domain allowlist from a comma-delimited list.
  - [`enable-test-on-host`](./usage#enable-test-on-host-command) — enable testing
    against a web app deployed on the host machine.
  - [`display-ai-config`](./usage#display-ai-config-command) — print the effective
    provider, model, and token mode as JSON.
- **Programmatic test & instruction management:**
  - [`upload-test-task`](./usage#upload-test-task-command) and
    [`upload-instruction-file`](./usage#upload-instruction-file-command) — create or
    replace markdown tasks and instruction/config files from stdin.
  - [`reset-test-config`](./usage#reset-test-config-command) — delete test tasks
    and/or instruction files to return to a clean state.
  - [`output-context-variables`](./usage#output-context-variables-command) — export
    context values produced by the latest run as flat JSON for reuse outside the
    container.

```shell
docker pull taojdcn/duotail-waterwheel:1.3.0
```

## 1.2.0

Builds on `1.1.0` with richer test configuration and new helper commands.

- **`preset-context.json`** — a single file to manage per-run context variables
  and to configure the **test flow** (execution order and dependencies between
  tasks).
- **New commands:**
  - [`manage-test-files`](./usage#manage-test-files-command) — add, list, and
    remove the markdown task files the agent runs.
  - [`preset-context`](./usage#preset-context-command) — manage the context
    variables and test flow stored in `preset-context.json`.

```shell
docker pull taojdcn/duotail-waterwheel:1.2.0
```

## 1.1.0

Added multi-platform support and the first set of command-line tools.

- **Multi-platform images** — published for both `linux/amd64` and `linux/arm64`.
- **New commands:**
  - [`stop-qa`](./usage#stop-qa-command) — stop the current QA run.
  - [`check-test-result`](./usage#check-test-result-command) — check the latest
    test results.
  - [`get-failure-detail`](./usage#get-failure-detail-command) — print a
    diagnostic report for the first failed test.
  - [`config-agent`](./usage#config-agent-command) — configure the AI provider,
    browser permissions, and access to a test website on the host.
  - [`manage-global-constants`](./usage#manage-global-constants-command) — manage
    global constants shared across all tests.
  - `manage-context-variables` — manage per-run context variable overrides.
    *(Replaced by [`preset-context`](./usage#preset-context-command) in 1.2.0.)*

:::note[Documentation for 1.1.0]
This site always documents the latest release. To read the documentation that
shipped with `1.1.0`, check out the
[`1.1.0` branch of the site repository](https://github.com/taodong/waterwheel-agent-site/tree/1.1.0)
and build it locally.
:::
