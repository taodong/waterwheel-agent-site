# Release and Support

## Release

The current Waterwheel agent release is `1.0.0`, distributed as a Docker image for anyone with a Mac to use for free. Please use the `1.0.0-mac` image tag.
 
**Docker image:** [hub.docker.com/r/taojdcn/duotail-waterwheel](https://hub.docker.com/r/taojdcn/duotail-waterwheel)
 
```shell
docker pull taojdcn/duotail-waterwheel:1.0.0-mac
```

See our [License and Disclaimer](./license) for full terms of use.
